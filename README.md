# Cognifyz Technologies — Web Developer Internship Landing Page

A responsive landing page promoting Web Developer Internship Opportunities at Cognifyz Technologies.

## Files
- `index.html` — page content and sections
- `style.css` — responsive layout, styling, and animations
- `script.js` — mobile navigation toggle

## Run locally
1. Download and extract the project ZIP.
2. Open `index.html` in your browser, or open the folder in VS Code and use the Live Server extension.

## Sections
- Hero headline and CTA buttons
- Program introduction
- Internship benefits
- Desired skills and qualifications
- Apply CTA
- Contact/inquiry footer

## Customization notes
- The Apply/Explore CTA currently links to `https://cognifyz.com/`. Update it to the official internship application URL when you have one.
- No specific internship duration or direct inquiry email was provided, so the page tells visitors to verify these details through Cognifyz Technologies' official website instead of inventing them.
- Google Fonts are loaded online; the page uses fallback fonts if unavailable.
